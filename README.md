# Intelligent Counterfeit Pharmaceutical Detection System

A web-based intelligent system for detecting counterfeit pharmaceutical products using a hybrid verification approach.

## Features

- Database verification using SQLite
- Machine Learning verification using XGBoost
- React frontend
- Node.js backend
- FastAPI ML service
- Drug verification based on:
  - Batch Number
  - Serial Number
  - Manufacturer
  - Manufacturing Date
  - Expiry Date
  - NAFDAC Number
