# Intelligent Counterfeit Pharmaceutical Detection System

A web-based intelligent system for detecting counterfeit pharmaceutical products using a hybrid verification approach that combines database lookup with machine learning to identify genuine and counterfeit drugs.


## Features

- Database verification using SQLite
- Machine Learning verification using XGBoost
- React-based user interface
- Node.js and Express backend
- FastAPI machine learning service
- Hybrid verification workflow (Database → Machine Learning)

### Drug Verification Parameters

The system verifies pharmaceutical products using:

- Batch Number
- Serial Number
- Manufacturer
- Manufacturing Date
- Expiry Date
- NAFDAC Registration Number



## Dataset

The machine learning model was trained using a **synthetically generated pharmaceutical dataset** developed specifically for this project. The dataset was designed to simulate realistic genuine and counterfeit pharmaceutical products while preserving characteristics commonly found on drug packaging.

### Dataset Summary

- **Total Records:** 20,000
- **Genuine Products:** 15,000 (75%)
- **Counterfeit Products:** 5,000 (25%)

### Dataset Features

The dataset contains pharmaceutical information and engineered features, including:

- Manufacturer
- Batch Number
- Serial Number
- NAFDAC Registration Number
- Manufacturing Date
- Expiry Date
- Shelf Life
- Batch Length
- Serial Length
- Manufacturer Encoding
- Batch Prefix Encoding
- Serial Postfix Encoding
- NAFDAC Validation Features
- Shelf-life Analysis
- Manufacturer Anomaly Detection
- Serial Repetition Detection
- Batch Validation Features

Counterfeit samples were generated by introducing realistic anomalies such as:

- Invalid or suspicious NAFDAC registration numbers
- Misspelled manufacturer names
- Invalid batch identifiers
- Repetitive or suspicious serial numbers
- Manufacturing and expiry date inconsistencies
- Abnormal shelf-life values
